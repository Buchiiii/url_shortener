# Understanding the problem
Users struggle with links that have long names.It makes it hard for them to remember all the names of the links they use.
**THE SOLUTION** is to build a url shortener, that shortens the link name and returns the shortened version. When the user types in the shortened url it should redirect them to the link they initially put

# Functional Requirements
* Users should be able to shorten their url links. System should auto-generate and return the shortened link for the user
* Users should be able to use their own alias for the shortened link name
* Users should be redirected to the link they initially shortened when they type in the shortened url
